====================
FINEXA GLASSMORPHIC DESIGN SYSTEM
Usage Examples and Implementation Guide
====================

This file demonstrates how to implement the glassmorphic design system throughout the application.
Copy these patterns into your XAML views for consistent theming.

WINDOW EXAMPLE:
Apply glassmorphic window style to your main window:
<Window x:Class="Lazarus.Desktop.MainWindow"
        Style="{StaticResource GlassmorphicWindowStyle}"
        Title="Lazarus" 
        Height="800" 
        Width="1200">
    
    <!-- Main content with glassmorphic background -->
    <Grid Background="{StaticResource BackgroundBrush}">
        <!-- Your content here -->
    </Grid>
    
</Window>

<!-- 
Typography usage:
- {StaticResource H1TextStyle} - Main page headers (32px bold)
- {StaticResource H2TextStyle} - Section headers (24px semibold)  
- {StaticResource H3TextStyle} - Subsection headers (18px medium)
- {StaticResource BodyTextStyle} - Regular text (14px normal)
- {StaticResource SecondaryTextStyle} - Muted text (14px normal, gray)
- {StaticResource SmallTextStyle} - Small text (12px normal, gray)
- {StaticResource MonoTextStyle} - Code text (13px Cascadia Code)
-->

<!-- 
Button styles:
- {StaticResource PrimaryGlassButtonStyle} - Main actions
- {StaticResource SecondaryGlassButtonStyle} - Secondary actions
- {StaticResource IconGlassButtonStyle} - Icon-only buttons
- {StaticResource NavGlassButtonStyle} - Navigation buttons
-->

<!-- 
Card styles:
- {StaticResource GlassCardStyle} - Static glass cards
- {StaticResource InteractiveGlassCardStyle} - Clickable cards with hover effects
-->

<!-- 
Status styles:
- {StaticResource SuccessStatusPillStyle} - Green success states
- {StaticResource WarningStatusPillStyle} - Yellow warning states
- {StaticResource ErrorStatusPillStyle} - Red error states
- {StaticResource PrimaryStatusPillStyle} - Purple primary states
-->

Color resources:

- {StaticResource GlassCardBrush} - Semi-transparent card backgrounds
