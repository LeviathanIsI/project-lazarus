## Implementation Details

### 1. AudioView.xaml (Complete UI)
- **Header**: Page title with quick stats (Total Files, Storage Used)
- **Toolbar**: Import, Record, Play/Pause, Stop, Delete, and Refresh buttons
- **Content Area**: 
  - DataGrid for audio files with columns: Name, Duration, Size, Format, Sample Rate, Modified, Actions

- **Status Bar**: Selected file display, playback progress with timer, and status indicator

### 2. AudioViewModel (Full MVVM Implementation)
- **Collections**: ObservableCollection<AudioItem> for managing audio files
- **Commands**: 
  - ImportCommand - Opens file dialog for multi-file import
  - RecordCommand - Stub for future recording feature
  - PlayPauseCommand - Toggles audio playback
  - StopCommand - Stops current playback
  - DeleteCommand - Removes audio files
  - RefreshCommand - Reloads audio file list
- **Properties**: 
  - SelectedItem, IsPlaying, CurrentPosition tracking
  - TotalFiles, TotalSizeDisplay for statistics
  - Playback progress with timer updates
- **DI Constructor**: Accepts IAudioService, ILogger<AudioViewModel>, IAppState

### 3. IAudioService Interface
```csharp
public interface IAudioService : IDisposable
{
    Task<IReadOnlyList<AudioItem>> GetAudioFilesAsync();
    Task ImportFileAsync(string filePath);
    Task<string> StartRecordingAsync();
    Task StopRecordingAsync();
    Task PlayAsync(string filePath);
    Task PauseAsync();
    void Stop();
    TimeSpan? GetPlaybackPosition();
    Task DeleteFileAsync(string filePath);
}
```

### 4. AudioService Implementation
- **NAudio Integration**: Uses WaveOutEvent and AudioFileReader for playback
- **File Management**: Imports files to %LOCALAPPDATA%\Lazarus\Shared-Resources\Import-Export\Audio
- **Metadata Extraction**: Reads duration and sample rate from audio files
- **Format Support**: MP3, WAV, FLAC, OGG, M4A, WMA, AAC
- **Recording**: Stub implementation with NotImplementedException (as required)

### 5. Dependency Injection
- AudioService registered as Singleton in ServiceCollectionExtensions
- AudioViewModel registered as Transient for fresh instances per view
- AudioView creates scoped DI container and retrieves ViewModel
